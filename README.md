## 作品主题

**「让自我关照变得低门槛、可执行。」**

我们都知道运动好、深呼吸好、晒太阳好，但情绪低谷时最缺的恰恰不是知识，而是「现在到底先做什么」的一个具体动作。

MoodTool 把循证的情绪调节方法（grounding、呼吸训练、行为激活、认知解离 等）拆解成一个个**5–10 分钟就能完成的小步骤**，并配合「天气 / 当前情绪 / 完全随机」三种切入方式，让用户在最不想思考的时刻也能直接开始。

## 功能一览

应用主界面分为三个 Tab，覆盖三种典型的「我现在该做点什么」场景：

### 1. 🌤 天气建议 — 顺着天气照顾自己
应用会自动获取当前位置的天气与温度（多源定位 + 离线兜底），从 7 大天气类别（晴 / 多云 / 雾 / 雨 / 雪 / 雷暴 / 默认）和 4 档温度（炎热 / 温暖 / 微凉 / 寒冷）中匹配出针对性的 3–4 条建议。

例如：
- ☀️ 晴天：多巴胺漫步（15 分钟阳光直射，促进血清素与维生素 D 合成）
- 🌧️ 雨天：白噪音 + 热饮仪式（激活副交感神经）
- ⛈️ 雷雨：4-7-8 呼吸 + 远离窗户（先安全感、再情绪）

> 网络异常时会自动切换到离线建议，永远不会"加载失败一片白"。

### 2. ⚡ 快捷调节 — 按情绪对症下药
9 张情绪卡片，每张展开后给出 3 个**有心理学依据**的具体做法：

| 情绪 | 给出的工具示例 |
|---|---|
| 😰 焦虑不安 | 5-4-3-2-1 感官 grounding · 4-7-8 呼吸 · 担忧外化记录 |
| 😤 愤怒烦躁 | 10 秒延迟法则（前额叶接管）· 物理能量释放 · 冷水降温（潜水反射） |
| 😢 悲伤低落 | 悲伤限定时间 · 微小行为激活 · 自然光照（天然抗抑郁剂） |
| 🤯 压力过载 | 任务原子化 · 四象限法则 · 15 分钟剧烈运动代谢皮质醇 |
| 😶 拖延无动力 | "只做 5 分钟" · 环境气味唤醒 · 即时奖励锚点 |
| 🌀 精神内耗 | 寻找反证记录 · 认知解离（"我产生了一个'我很失败'的念头"）· STOP 技术 |
| 😵‍💫 注意力涣散 | 物理隔离分心源 · 单任务原则 · 白噪音屏障 |
| 😨 社交焦虑 | 注意力外移 · 万能话题准备 · 接纳紧张反应 |
| 😴 失眠多梦 | 肌肉渐进放松（PMR）· 床铺功能纯化（刺激控制疗法）· 思维日志转存 |

### 3. 🎡 心情转盘 — 让随机替你做决定
当连"该选哪一个"都做不到时，转一下就好。五个**等概率**选项（喝茶 / 站起 / 刷 10 分钟手机 / 运动 / 吃零食），每一个都是经过设计的「合法的小奖励」——包括"刷 10 分钟手机"，因为有掌控的小放纵比偷偷摸摸的大放纵更不容易诱发负罪感。

转盘动画使用 PIL 超采样 + LANCZOS 抗锯齿，转得真的丝滑。

## 想传达的心理健康知识

MoodTool 把以下核心理念藏进了每一个交互：

1. **行动先于动力（Behavioral Activation）**
   不是"等想做了再做"，而是"哪怕做 5 分钟也算开始"。所有建议都被刻意压到 5–15 分钟之内，绕过"启动阻力"。

2. **身体先于头脑（Bottom-up Regulation）**
   呼吸、冷水、晒太阳、运动、热饮——这些都是直接作用于自主神经系统的"硬件级"调节，比"想开点"快得多也实在得多。

3. **认知解离（Cognitive Defusion，ACT 流派）**
   "你不是你的想法。"快捷调节里的『精神内耗』一栏专门写了这一点：把"我很失败"重述为"我产生了一个'我很失败'的念头"，让人和念头之间出现一道缝隙。

4. **自我关照不需要仪式感（Self-Compassion）**
   一杯热茶、起身走两分钟、看 5 分钟雪——好的情绪调节往往简单到让人怀疑"这也算？"。它就是算。

5. **掌控感是情绪稳定的基础（Sense of Agency）**
   "刷 10 分钟手机"被明确写进转盘，是因为**有意识地小放纵**比**失控地大放纵**对心理健康更友好。设定窗口、按时停下，本身就是练习自我掌控。

6. **接住自己，而不是修理自己**
   应用不会给你打分、不会评估你"今天情绪几分"、不会让你打卡。它只在你需要的时候出现，提供一个具体的下一步——这就是它全部的功能。

## 快速开始

### 直接运行（推荐用 Python 3.9+）
```bash
pip install requests certifi pillow
python mood_tool.py
```
> Pillow 是可选依赖。没有它转盘也能跑，只是边缘没有抗锯齿。

### 打包成 Windows 单文件 exe
```bash
# 双击 build.bat 即可，或者：
python build.py
```
产物：`dist/MoodTool.exe`，自带彩虹图标，无需控制台窗口，把 certifi 证书一起打进去保证 HTTPS 正常。

更多打包参数见 `build.py` 顶部注释（`--no-onefile` 目录模式 / `--console` 保留控制台调试 / `--icon` 自定义图标 等）。

## 技术亮点（写给同样在写 Tkinter 的同学）

- **真实时间驱动的动画引擎**：用 `time.perf_counter()` + 漂移补偿调度做到逼近 120Hz，告别 `after(16ms)` 的累计漂移。
- **PIL 超采样抗锯齿**：Tk 原生 `create_arc` 没有 AA，扇形边缘很糙。改成在 3× 画布上 PIL 绘制 + LANCZOS 下采样，肉眼可见地光滑一档。
- **亚像素平滑滚动**：`yview_moveto` 分数滚动 + 速度累加 + 0.92 衰减，鼠标滚轮不再"一行一行跳"。
- **多源定位 + 离线兜底**：天气接口失败时自动降级到内置离线建议，断网也能用。
- **PyInstaller 友好**：把 `certifi` 证书一并打包，避免 exe 打开后 HTTPS 调用直接挂掉。
